Multi-function assignment (blue section in Pane 2): When you procure or select a system, you can check other pending functions to assign them the same system. This:
  • Auto-resolves checked functions (they show "Resolved via HR" in Pane 1)
  • Creates the REALIZES edge from new system → those functions
  • Inherits the sharing decision (if Workday is shared for HR, it's shared for Procurement too)
  • Appears in the summary as a batch resolution — single procurement, multiple functions served
Two types of cost split in Pane 3:
  • Transition cost — SAP costs while both successors still depend on it (temporary, during migration)
  • Ongoing cost — Workday shared service cost allocation (permanent, post-transition)
These are semantically different: transition costs end when migration completes; ongoing costs persist.
