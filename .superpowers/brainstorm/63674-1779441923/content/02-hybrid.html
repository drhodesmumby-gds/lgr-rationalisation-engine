Key principles:
  • System name, vendor, and function/capability always visible in both modes
  • Focus mode: one system at a time with full form + field hints (like Build from Scratch cards)
  • Bulk mode: spreadsheet-density with column groups for quick multi-system edits
  • Completeness status (✓/⚠/✗) visible per system in both modes
  • Sticky headers in table, sticky list header in Focus mode
  • Progress bar shows overall completeness
  • Domain grouping available via Filter in the list panel
