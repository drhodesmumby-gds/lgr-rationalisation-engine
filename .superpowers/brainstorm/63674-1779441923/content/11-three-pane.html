Three-pane design:
  • Left: System list with domain groups, search, progress
  • Centre: System properties (identity, contract, technical) — facts about THIS system
  • Right: Relationships — capabilities provided (toggleable pills), consuming systems with per-system capability pills (toggle which caps each consumer uses), dependencies, sharing
  • Each consuming system shows the provider's capabilities as small pills — toggle on/off which ones it actually uses
  • Right panel only has content when the system provides capabilities or has dependencies — otherwise it shows "No relationships defined"
