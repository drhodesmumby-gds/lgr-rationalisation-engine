How should capability dependencies be shown?

These define CONSUMES_CAPABILITY edges. "SAP provides payments → Liquidlogic consumes payments from SAP."

Option 1: Inline Lists (per-system)

Show "provides to" and "depends on" as simple lists within each system's detail. Edit from either side.
